# 🌾 CropPilot – Smart Farming Assistant

CropPilot is an AI-powered smart farming application designed to help farmers make better agricultural decisions using machine learning, data analysis, and web technologies.

The application provides crop recommendations based on soil and environmental conditions, plant disease detection from leaf images, weather information, agricultural market insights, crop nutrition details, and farming guidance.

## Key Features

- 🌱 **Crop Recommendation** – Recommends suitable crops based on soil and environmental conditions.
- 🍃 **Plant Disease Detection** – Identifies plant diseases from leaf images using deep learning.
- 🌦️ **Weather Information** – Provides weather updates to support farming decisions.
- 📊 **Market Insights** – Displays agricultural commodity price information.
- 🥗 **Crop Nutrition** – Provides crop-specific nutritional information.
- 📅 **Crop Calendar** – Helps organize farming activities and timelines.

## Tech Stack

**Python · Flask · Scikit-learn · TensorFlow/Keras · Pandas · NumPy · HTML · CSS · JavaScript**

## Project Objective

CropPilot combines machine learning, data analysis, and web technologies to provide a practical digital assistant for smarter and more informed farming.
